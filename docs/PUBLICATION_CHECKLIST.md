# Publication and reproducibility checklist

The repository is public, but project source files and media are not yet released.

- [ ] Verify permission to publish co-authored research/code and accurately credit contributors.
- [ ] Check university/supervisor requirements for the thesis, slides and LabVIEW files.
- [ ] Review documents for private information or third-party media.
- [ ] Review demo video for faces, voices and identifying information; obtain consent where required.
- [ ] Keep STM32, Python HMI and LabVIEW controller variants distinguished and accurately documented.
- [ ] Confirm serial baud rate, sampling rates, PWM limits, hardware safety and test results.
- [ ] Upload the missing MATLAB/Simulink files or raw data only if they become available and are cleared for sharing.
- [ ] Agree on a license with relevant rights holders before applying one.

The published overview should not imply that software files or experimental datasets are already available.
