# Helicopter Demonstration Media

The original experimental video has been re-encoded to a smaller MP4 preview (`helicopter_demo.mp4`, approximately 5.1 MiB). The intended file path is:

```
media/helicopter_demo.mp4
```

This is a demonstration of the physical 3-DOF helicopter prototype. Controller behavior should be described using the controller actually operating during the recording; do not claim the video demonstrates the currently published hybrid controller without confirming that correspondence.

A preview image (`demo_preview.jpg`) is also available in the prepared package. The MP4 demonstration has now been uploaded successfully. A standalone preview image remains to be published, if desired.

See [experimental results](../docs/EXPERIMENTAL_RESULTS.md) for thesis measurements, which are reported separately from this video.
